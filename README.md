# kintai
## jarvis.html — 自分専用AIアシスタント

ブラウザで動く「ジャーヴィス」です。合言葉 (または手を2回叩く) で呼び出し、Claudeが考えて、ElevenLabsの声で答えます。

1. `jarvis.html` を HTTPS で開く (GitHub Pages など。マイクは HTTPS か localhost でしか使えません)。Chrome 推奨。
2. 「設定」で、名前・呼び方・仕事、やってほしいこと、合言葉、Claude APIキーを登録。
3. 任意で ElevenLabs のAPIキーと、ボイスデザインで作った日本語の声のボイスIDを登録 (未設定ならブラウザ標準の声)。
4. 中央の円をタップして起動し、「ジャーヴィス、今日やることを整理して」と話しかける。

- APIキーと設定はこのブラウザの localStorage にだけ保存されます。共有PCでは使わないでください。
- Claude API は従量課金です (Claudeの月額プランとは別)。
- 使わないときはタブを閉じてください。開いている間はマイクで合言葉を聞き続けます。
